# Deepseek Chan · 桌宠

一个 Windows 桌面宠物（Python + tkinter，约 3200 行）。她待在屏幕右下角呼吸眨眼，被拖走会自己跑回角落，
也能替你把话带给 DeepSeek。

![桌宠](assets/screenshot-pet.png)

> 非官方同人作品：角色设计 **amenmily2050**（「Deepseek Chan」分视图），与 DeepSeek 官方无关。
> 代码可自由阅读参考；美术素材仅供个人非商业用途，详见 NOTICE.md。

## 能做什么

- **97 段动作素材**：待机 / 移动 / 点击回应 / 拖拽 / 转圈 / 余额事件 / 80 个随机小动作；
  自带 ffmpeg 流式解码 VP9+alpha，逐片裁剪 + 统一身高缩放，色键透明
- **交互**：单击互动、双击开对话框（520x782 精简聊天面板：聊天 / 状态 / 工作台 / 历史 / 功能 / 设置）
- **和 DSH 联动**：读余额与忙碌状态、把任务派给本机 DeepSeek Harness
- **AI 对话（不需要 API token）**：从本机 DSH 的会话记录里读回回答，见 AI对话说明.md
- **对齐原版行为**：默认待在原地（no_move）、被拖走自己回角落（return_corner）、
  全屏应用时自动隐藏、播放速度 0.5~2 倍
- 60 帧动画引擎、气泡对话、音符 / Zzz / 汗滴特效、本地合成的音效

## 跑起来

    # 需要 Python 3.10+（tkinter + Pillow）
    python src\main.py

或者双击 启动桌宠.bat（会优先用 DSH 自带的 Python 运行时，找不到再退回 PATH 里的 pythonw）。

## 1. 30 秒上手

1. 双击桌面上的 **Deepseek Chan 桌宠** 图标（或本目录里的 启动桌宠.bat）—— 小鲸鱼会出现在屏幕右下角
   （找不到窗口就看看任务栏 / 屏幕各处，她可能被你拖走了）。
   桌面快捷方式直接指向 pythonw.exe，不会闪黑框；图标来自 assets/pet.ico。
2. **单击**她 → 冒泡说话 + 小动作 + 音效；**双击** → 打开对话框；**右键** → 功能菜单。
3. 想让她消失：右键 → 退出桌宠；或双击 **退出桌宠.bat**。
4. 想开机自动出现：双击 **开机自启-开启.bat**（取消：开机自启-关闭.bat）。

> 环境要求：Windows + Python 3.10 以上（带 tkinter 和 Pillow）。
> 启动器会优先用 DSH 自带的运行时（`%USERPROFILE%\.dsh\dsh-runtimes\...\pythonw.exe`），
> 找不到就退回 PATH 里的 `pythonw`。要指定解释器，直接把路径写进 `python-path.txt`。

## 4. 动画与特效（60 帧）

- **60 帧动画引擎**：主循环用固定步长调度 —— 按 1/60 秒推进，再回表补偿 Tk after() 的取整误差，
  实测待机 59.9 fps、走动 60.1 fps；所有动作都是**时间驱动**的，即使某帧被系统拖慢，动画节奏也不会变。
- **会动**：呼吸（上下约 2px + 轻微挤压）、摆头、蹦跳、转身（正面→侧面→背面→正面）、
  唱歌（左右摇摆）、走路（起伏 + 前倾 + 朝移动方向镜像翻转）、打盹（慢呼吸 + Zzz）。
- **会溜达**：待机 10~24 秒后随机挑一个目的地，平滑起步/收步走过去，走完回到待机；
  你刚拖过她或点过她，会先安静 6~10 秒。
- **特效层**：爱心、音符、星星、Zzz、汗滴都是本地用 Pillow 画的（4 倍超采样），
  从头顶冒出、向上飘、尾段缩小消失；点击 / 双击 / 唱歌 / 任务完成 / 升级会触发不同特效。
- **性能**：帧缓存有 LRU 上限（340 帧），长时间运行不会一直涨内存；
  窗口是 Windows 色键透明，透明区域的鼠标点击会穿透到桌面。

### 这次修掉的两个气泡 bug

1. **文字会顶出气泡**：原来按「字符数 × 14px」估算宽度，而中文 11pt 其实是 ~15px/字 → 越界。
   现在用 Tk 字体度量（font.measure）**按像素断行**，气泡宽高由实测文字尺寸推导，绝对不会溢出。
2. **气泡后面有白框**：原来气泡窗口背景是纯白，圆角卡片外面就露出一个白色矩形。
   现在气泡窗口也用了色键透明（#fe00fe），只有圆角卡片和尾巴可见，卡片外完全透明。
   （顺带查出并修掉了一个更隐蔽的 bug：素材填充色写成 (254,0,254) 而窗口色键写成 #ff00fe，
   两者不一致会让整个桌宠窗口显示成一块品红色 —— 现在色键统一在 pet_core.CHROMA 定义。）

## 6. DSH 联动：读什么、怎么派活

**只读的部分**（全部来自 `%USERPROFILE%\.dsh`，不写任何 DSH 文件）：

| 数据 | 来源 |
|---|---|
| 余额 / 今日消耗 / 逐轮 token | `.dshw-usage.json` |
| 轮次序号（判断"又完成一轮"） | `.dshw-turn.json` |
| 是否正在干活 | `sessions\**\session.v4.jsonl.zstd` 的修改时间 |
| 会话标题 / 工作区 / 文件大小 | `storages\session_projcache\**`、`storages\workspace.json`、`sessions\**` |
| 技能 / 插件 / profile | `skills\*\SKILL.md`、`profiles\<profile>\package.json` |

**动作的部分**：

- 「聚焦 / 启动 DSH」：按窗口标题找到客户端窗口并置前；没开就启动 `DeepSeek Harness.exe`。
- 「派活」：把文本放进剪贴板 + 聚焦 DSH（默认方式，最稳）；在「设置」里打开 **允许自动输入到 DSH** 后，会直接用 SendInput 逐字敲进 DSH 输入框（Unicode，支持中文），可选自动回车。
- 「打开」类：用系统默认方式打开目录或文件。

> 为什么默认是"复制 + 聚焦"而不是直接注入：DSH 的输入框焦点你随时可能在用，直接敲字有风险；自动输入是可选开关，默认关闭。
> 另外 DSH 的本地 HTTP 服务需要鉴权（401），桌宠不去碰它，只读文件 + 模拟键鼠，边界清楚。

## 7. 素材是怎么来的

原始素材：`assets/sheet.jpg`（850×638 的角色分视图，就是你给的那张）。
`tools/extract_sprites.py` 做四件事，全自动：

1. 以白底为背景做**边界洪泛**（只吃掉与边缘连通的背景，保留围裙、蕾丝这些白色内部区域）；
2. 按列墨迹密度**自动定位**四个人物与三个表情头的边界框；
3. 只保留够大的**连通块**——手写签名、"Deepseek Chan" 标题、音符、分割线会被当成杂物丢掉；
4. **去白边**（对半透明边缘做反预乘），导出透明 PNG，并生成预览图。

切出来的素材（在 `assets/sprites/`）：

| 文件 | 来源 | 尺寸 | 用途 |
|---|---|---|---|
| front.png | Front View | 209×270 | 默认姿态、呼吸/弹跳动画 |
| side.png | Side View | 172×264 | 转身彩蛋 |
| back.png | Back View | 200×263 | 转身彩蛋 |
| sing.png | Singing Pose | 229×272 | 唱歌/庆祝动画（左右摆） |
| face_neutral / face_happy / face_laugh | Expressions | ~120×150 | 气泡里的表情贴图 |
| mini.png | Proportions | 99×156 | 迷你形态 |
| emblem.png | Apron Emblem | 78×71 | 图标素材 |

想重新切一遍：对话框 →「关于」→「重新生成素材」，或者直接跑

```powershell
& "<python>" "tools\extract_sprites.py"
```

音效在 `assets/sounds/`，由 `src/sounds.py` 用标准库合成（点击、双击、开心、完成、提醒、撒花、升级…），首次运行自动生成。

## 10. 常见问题

**Q：双击 bat 没反应？**
看 `logs/pet.log`。多数是没找到 Python——把 `pythonw.exe` 完整路径写进 `python-path.txt` 再试。

**Q：桌宠跑到屏幕外面 / 找不到了？**
对话框 →「设置」→「重置桌宠位置」，或者删掉 `data/config.json`（key `x`/`y` 为 -1 时回到右下角）。

**Q：想在透明区域点击穿透？**
透明像素本来就是穿透的（Windows 色键分层窗口），只有角色身上会接收点击。

**Q：会写我的 DSH 配置吗？**
不会。桌宠对 `~/.dsh` 全是只读；只有「打开目录」这种操作，以及往剪贴板放文本。

**Q：气泡里为什么没有 emoji 了？**
Tk 8.6 在 Windows 上渲染不了彩色 emoji，会把 ✅ 📊 📋 🪙 这类字形画成**描边方框**（看起来就是"蓝色底框"）。
所以桌宠所有对白、提示、菜单都不再用 emoji，只保留 ♪ ✕ 这类能正常显示的字符；气泡里要表达情绪就靠文字 + 爱心/音符特效。
改完文案可以跑 `python tools/check_emoji.py` 自查，它会列出所有会被画成方框的字符。

**Q：她怎么不动了 / 我不想要她乱跑？**
「设置」里两行开关：**动画与特效（60 帧）**、**自由走动**；右键菜单里也有。关掉走动她就待在原地，
但呼吸、小动作、特效还在；关掉动画就完全静止（最省电）。

**Q：怎么自己验证 / 出了 bug 怎么复现？**
三个脚本：
- `python tools/selftest.py` —— 19 条断言（帧率、走动、特效、气泡排版与透明底、队列上限、双击不重复计数、对话框六个视图、模型权限前缀…）
- `python tools/stress.py` —— 压测：75 秒内随机点击/双击/拖拽/缩放/换姿态/开关对话框/番茄钟/隐藏，把 Tk 回调异常和状态漂移写进 logs/stress_*.txt
- `python tools/_perf.py` —— 帧率实测

**Q：动画真的是 60 帧吗？**
是。可以用 `python tools/_perf.py` 自己量：待机 / 走动各跑 10 秒，会打印实测 fps（本机 59.9 / 60.1）。
Windows 默认定时器精度约 15.6ms，会把 60 帧压到约 56，所以桌宠启动时会调用 timeBeginPeriod(1)。

**Q：两个实例？**
有互斥锁 + 窗口检测，重复启动会自动退出。
